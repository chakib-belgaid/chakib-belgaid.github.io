01

Contexte et problème

Les agences publicitaires avaient besoin d’un système d’automatisation agentique ad/ops. Mon travail reliait workflows no-code, orchestration LLM, interfaces produit et infrastructure déployable.

02

Responsabilité et contribution

AI Research Engineer / Lead AI Engineer, 2024–aujourd’hui. Pilotage de l’architecture, du développement et du déploiement, avec coordination d’une équipe technique de deux personnes.

Responsabilités

  • Pilotage du développement de l’architecture API et du frontend jusqu’au déploiement.
  • Création des chemins CI/CD avec Cloud Run, Secret Manager, Artifact Registry, Docker et GitHub Actions.
  • Développement de pipelines à décodage contraint et sorties structurées.
  • Optimisation de l’inférence, refonte des prompts et flux d’outils, fine-tuning d’un modèle local de classe 7B.
  • Pour un déploiement dans l’infrastructure d’un client, compilation du code en logiciel exécutable afin de livrer sans remettre le code source.
03

Architecture et flux de données

La plateforme relie workflows clients no-code, API, frontend, orchestration multi-agents et sorties LLM structurées. J’ai conçu et déployé la plateforme sur GCP avec Cloud Run, Docker, GitHub Actions, Artifact Registry et Secret Manager. Cette description reste générale : topologie client et implémentation sont privées.

  1. Workflows clients no-code
  2. Intégration API et frontend
  3. Orchestration multi-agents
  4. Pipelines LLM à sorties structurées
  5. Déploiement GCP
04

Décisions d’ingénierie

Livrer un logiciel exécutable dans l’infrastructure client.

Le client souhaitait un déploiement chez lui ; la direction était préoccupée par la distribution du source. La compilation répondait au format de livraison. Elle ne garantit ni protection de la propriété intellectuelle ni impossibilité de rétro-ingénierie.Alternative écartée: Distribuer le code source comme paquet de déploiement.

05

Fiabilité, sécurité et évaluation

  • Le décodage contraint et les sorties structurées imposent des interfaces conformes au schéma. Cette conformité ne prouve pas la justesse sémantique.
  • La CI/CD et GCP Secret Manager prennent en charge déploiement et gestion des secrets.
  • Code client, captures, jeux d’évaluation et manifests de déploiement ne sont pas inclus dans cette présentation publique.
